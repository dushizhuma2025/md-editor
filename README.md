## 🛠️ 本地开发指南

如果您希望在本地运行或基于本项目继续定制，请按照以下步骤操作：

### 环境要求
- **Node.js** >= `22.16.0`
- **Package Manager**：推荐使用 `pnpm`

### 步骤说明

1. **克隆项目**
   ```bash
   git clone https://github.com/dushizhuma2025/md-editor.git
   cd md-editor
   ```

2. **安装依赖**
   ```bash
   pnpm install
   ```

3. **启动本地开发服务器**
   ```bash
   pnpm start
   ```
   启动后，浏览器会自动打开或你可以访问终端提示的本地开发地址（通常是 `http://localhost:5173`）。

4. **构建生产包**
   ```bash
   pnpm web build
   ```
